# Ansible Playbook Using Tags, Skip-Tags, and When Conditions

## Description

Create an Ansible playbook that uses tags, skip-tags, and when conditions to control task execution. The screenshots document the workflow definitions and the selective execution of tasks based on conditions and tags.

## Learning outcomes

- Organize tasks with Ansible tags.
- Skip selected tasks during execution.
- Apply conditional logic with when statements.
- Understand task control flow in automation.
