# Nginx Static Web Hosting on All Slave Servers Using Ansible Playbook

## Description

Use an Ansible playbook to install Nginx across all slave servers and host a static webpage. The exercise demonstrates automation of package installation, configuration deployment, and validation of the final web output.

## Learning outcomes

- Write and execute an Ansible playbook for multi-host deployment.
- Install and configure Nginx on remote servers.
- Confirm Nginx service readiness and static content delivery.
