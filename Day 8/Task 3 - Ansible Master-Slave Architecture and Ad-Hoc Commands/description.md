# Ansible Master-Slave Architecture and Ad-Hoc Commands

## Description

Set up an Ansible master-slave architecture, verify the installed version, create secure password handling, and run ad-hoc commands to confirm remote server communication. The evidence captures the setup, troubleshooting, and successful connectivity checks.

## Learning outcomes

- Configure an Ansible control node and managed hosts.
- Generate and use encrypted passwords securely.
- Run ad-hoc commands for remote administration.
- Validate communication between master and slave systems.
