# Day 8 - GitHub Actions and Ansible automation

This day covers Linux command practice, GitHub Actions CI/CD workflows, Ansible master-slave architecture, static web hosting with Nginx, and conditional playbook execution using tags and when conditions.

## Tasks

1. [10 Linux commands](<Task 1 - 10 Linux commands/description.md>) - Practice Linux commands and capture the terminal output.
2. [GitHub Actions with CI/CD automation](<Task 2 - GitHub Actions with CICD Automation/description.md>) - Create and run GitHub Actions workflows to automate CI/CD tasks.
3. [Ansible master-slave architecture and ad-hoc commands](<Task 3 - Ansible Master-Slave Architecture and Ad-Hoc Commands/description.md>) - Configure a master-slave setup and verify remote execution through ad-hoc commands.
4. [Nginx static web hosting on all slave servers using Ansible playbook](<Task 4 - Nginx Static Web Hosting on All Slave Servers Using Ansible Playbook/description.md>) - Deploy Nginx to slave servers and serve a static page through Ansible.
5. [Ansible playbook using tags, skip-tags, and when conditions](<Task 5 - Ansible Playbook Using Tags, Skip-Tags, and When Conditions/description.md>) - Control playbook execution with tags, skip-tags, and conditional logic.
