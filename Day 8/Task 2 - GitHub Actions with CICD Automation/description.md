# GitHub Actions with CI/CD Automation

## Description

Create a GitHub Actions workflow that automates a CI/CD pipeline and tracks its execution from the repository's Actions tab. The screenshots show the workflow start, active status, and successful completion.

## Learning outcomes

- Create and configure a GitHub Actions workflow.
- Understand CI/CD automation triggers and jobs.
- Review workflow logs and confirm successful execution.
