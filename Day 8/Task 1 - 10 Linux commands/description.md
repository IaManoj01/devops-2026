# 10 Linux Commands

## Description

Practice ten Linux commands and capture the terminal output as evidence. These commands help reinforce shell usage, command syntax, and the interpretation of results in a Linux environment.

## Learning outcomes

- Execute common Linux commands.
- Observe output and understand command behavior.
- Build confidence with daily shell operations.
