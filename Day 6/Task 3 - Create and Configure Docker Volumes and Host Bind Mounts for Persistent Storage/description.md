# Docker Volumes and Host Bind Mounts for Persistent Storage

## Description

Create and configure Docker storage to retain data outside a container's writable layer. Compare a Docker-managed volume with a host bind mount and verify that the configured storage can be used by containers.

## Learning outcomes

- Explain why container workloads may need persistent storage.
- Distinguish Docker volumes from host bind mounts.
- Configure and verify storage-backed container communication.
