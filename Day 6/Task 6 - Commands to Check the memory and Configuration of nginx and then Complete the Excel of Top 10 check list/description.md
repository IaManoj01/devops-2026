# Check Memory and Nginx Configuration; Complete the Top 10 Checklist

## Description

Use Linux commands to inspect memory and review the Nginx configuration, then complete the supplied top-10 readiness checklist workbook. Record observations in the workbook and avoid recording secrets or sensitive host details.

## Learning outcomes

- Inspect memory and system capacity from the command line.
- Locate and review Nginx configuration and service information.
- Capture operational checks in a structured checklist.
