# Build and Push a Private Docker Image to Docker Hub

## Description

Build a Docker image and publish it to a private Docker Hub repository. The screenshots document the image-publishing workflow and the private repository. Avoid including access tokens or passwords in screenshots or documentation.

## Learning outcomes

- Build or tag an image for a remote registry.
- Authenticate securely to Docker Hub.
- Push an image to a private repository and verify that it is present.
