# Linux 10 Commands

## Description

Practice ten Linux commands and save terminal screenshots of the work. This recurring exercise reinforces command-line fluency and provides a quick reference to the results observed during the session.

## Learning outcomes

- Run common Linux command-line utilities.
- Interpret their output in the context of the system.
- Build confidence through repeated hands-on practice.
