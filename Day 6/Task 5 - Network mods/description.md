# Docker Network Modes

## Description

Explore Docker network modes and observe how they affect container connectivity. The screenshots document the network configurations and command-line or container output captured during the exercise.

## Learning outcomes

- Recognize common Docker networking modes.
- Compare how containers connect to each other and to the host.
- Use network inspection and testing to understand connectivity.
