# Day 6 - Secure access, Docker, and system checks

The exercises cover Linux command practice, secure developer access, persistent Docker storage, private image publishing, Docker network modes, and a memory/Nginx readiness checklist.

## Tasks

1. [Linux 10 commands](<Task 1 - Linux 10 commands/description.md>) - Practice and document ten Linux commands.
2. [Configure secure developer access](<Task 2 - Configure Secure Developer Access to Assigned Linux Distribution/description.md>) - Configure and verify a secure access path to the assigned Linux environment.
3. [Docker volumes and bind mounts](<Task 3 - Create and Configure Docker Volumes and Host Bind Mounts for Persistent Storage/description.md>) - Compare persistent Docker volumes and host bind mounts.
4. [Build and push a private Docker image](<Task 4 - Build and Push a Private Docker Image to Docker Hub/description.md>) - Build an image and publish it to a private Docker Hub repository.
5. [Docker network modes](<Task 5 - Network mods/description.md>) - Explore Docker networking modes and their connectivity behavior.
6. [Memory, Nginx, and readiness checklist](<Task 6 - Commands to Check the memory and Configuration of nginx and then Complete the Excel of Top 10 check list/description.md>) - Check memory and Nginx configuration and complete the included checklist workbook.
