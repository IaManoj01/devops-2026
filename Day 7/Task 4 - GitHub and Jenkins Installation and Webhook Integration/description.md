# GitHub and Jenkins Webhook Integration

## Description

Install or configure Jenkins and connect it to GitHub with a webhook so a repository event can trigger a Jenkins build. Verify the trigger configuration and confirm that a webhook-triggered run succeeds.

## Learning outcomes

- Connect a GitHub repository to Jenkins.
- Configure webhook-triggered builds.
- Verify trigger delivery and observe the resulting Jenkins execution.
