# 10 Linux Commands

## Description

Practice ten Linux commands and capture terminal output as evidence. Use the examples to reinforce shell usage and the interpretation of command results.

## Learning outcomes

- Execute common Linux commands.
- Read and interpret terminal output.
- Build consistent command-line habits.
