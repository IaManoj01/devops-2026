# Day 7 - Jenkins and delivery pipelines

This day covers Linux command practice, SUSI OS exploration, Jenkins setup and job scheduling, GitHub webhook integration, and single-branch and multibranch pipeline runs.

## Tasks

1. [10 Linux commands](<Task 1 - 10 Linux commands/description.md>) - Practice Linux commands and capture the terminal output.
2. [SUSI OS](<Task 2 - SUSI OS/description.md>) - Explore SUSI OS and record the observed environment and exercise evidence.
3. [Jenkins job creation, ordering, and scheduling](<Task 3 - Jenkins Job Creation, Ordering, and Scheduling/description.md>) - Create Jenkins jobs, control their order, schedule execution, and inspect results.
4. [GitHub and Jenkins webhook integration](<Task 4 - GitHub and Jenkins Installation and Webhook Integration/description.md>) - Connect GitHub events to Jenkins and verify webhook-triggered execution.
5. [Pipeline](<Task 5 - Pipeline/description.md>) - Run and inspect single-branch and multibranch Jenkins pipelines.
