# Jenkins Pipelines

## Description

Run and inspect both single-branch and multibranch Jenkins pipelines. The screenshots capture execution and result views for each pipeline style.

## Learning outcomes

- Distinguish a single-branch pipeline from a multibranch pipeline.
- Observe pipeline execution in Jenkins.
- Inspect build results for each pipeline configuration.
