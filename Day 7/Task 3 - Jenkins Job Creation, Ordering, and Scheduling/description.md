# Jenkins Job Creation, Ordering, and Scheduling

## Description

Install the Java prerequisite, access the Jenkins dashboard, create and order Jenkins jobs, and configure scheduled execution. The saved screenshots capture the setup, job ordering, scheduling, and execution output.

## Learning outcomes

- Recognize the Java prerequisite for Jenkins.
- Create and organize Jenkins jobs.
- Configure job scheduling.
- Start a job and inspect its output.
