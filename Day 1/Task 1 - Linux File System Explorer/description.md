# Linux File System Explorer

## Description

Explore the Linux filesystem hierarchy and practice navigating directories and locating important system and user files. The exercise builds familiarity with where configuration, executable, temporary, and home-directory data are typically organized.

## Learning outcomes

- Navigate the filesystem from both the root and the current working directory.
- Identify common directories and inspect their contents.
- Use paths and directory listings to locate files.
