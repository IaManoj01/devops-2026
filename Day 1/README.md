# Day 1 - Linux fundamentals

This day introduces Linux filesystem navigation and inspection, command-line investigation, file permissions, and process management. Each task folder keeps its original screenshot evidence alongside a task-specific description.

## Tasks

1. [Linux File System Explorer](<Task 1 - Linux File System Explorer/description.md>) - Explore the Linux directory hierarchy and locate important system and user files.
2. [Linux Commands Investigation](<Task 2 - Linux Commands Investigation/description.md>) - Investigate common commands and their output to build command-line familiarity.
3. [Linux Permissions](<Task 3 - Linux Permissions/description.md>) - Read and reason about Linux file and directory permissions.
4. [Linux Processes](<Task 4 - Linux Processes/description.md>) - Inspect running processes and practice basic process-management concepts.
