# Linux Permissions

## Description

Practice reading Linux file and directory permissions and understand how access is represented for an owner, a group, and other users. The exercise introduces the relationship between read, write, and execute permissions and access to filesystem objects.

## Learning outcomes

- Interpret symbolic permission output.
- Distinguish owner, group, and other permission classes.
- Understand how permissions affect files and directories.
