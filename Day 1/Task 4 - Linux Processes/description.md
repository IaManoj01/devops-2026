# Linux Processes

## Description

Inspect processes running on a Linux system and learn the basic information used to identify and monitor them. This exercise introduces process state and resource usage as useful starting points for troubleshooting.

## Learning outcomes

- View and interpret a process listing.
- Identify process-related details such as identifiers and resource use.
- Understand why process inspection is useful during basic diagnosis.
