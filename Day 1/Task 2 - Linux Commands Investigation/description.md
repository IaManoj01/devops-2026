# Linux Commands Investigation

## Description

Investigate common Linux commands by running them, observing their output, and understanding what each command is useful for. This is a practical introduction to working in a shell and using command output to answer basic system questions.

## Learning outcomes

- Run and interpret common command-line utilities.
- Relate command output to the current system and working directory.
- Build confidence exploring Linux without relying exclusively on a graphical interface.
