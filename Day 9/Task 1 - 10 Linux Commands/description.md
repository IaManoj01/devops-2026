# 10 Linux Commands

## Description

Practice Linux commands and save terminal screenshots of the commands and their output. Reviewing the captured examples reinforces command syntax and everyday shell use.

## Learning outcomes

- Execute common Linux command-line utilities.
- Read and interpret terminal output.
- Build familiarity with routine Linux shell operations.
