# Day 9 - Blue-Green deployment and Linux command practice

This day combines Linux command practice with a Blue-Green deployment exercise. The evidence follows the setup of blue and green EC2 environments, a change to the green environment, and the recorded environment states before and after the swap.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 Linux Commands/description.md>) - Practice Linux commands and retain screenshots of the terminal output.
2. [Blue-Green Deployment Strategy](<Task 2 - Blue Green deployment strategies/description.md>) - Set up parallel blue and green EC2 environments, apply a change to the green environment, and document the before-and-after swap states.
