# Deploy a Static Page in AWS

## Description

Deploy a static webpage using AWS-hosted infrastructure and verify that it can be served. The saved screenshots capture the Linux and Windows deployment environments, providing evidence of the deployment work on both platforms.

## Learning outcomes

- Understand the basic steps involved in hosting static content on a server.
- Work with Linux and Windows server environments.
- Verify the web page from the configured host.
