# Create Servers in AWS (Windows and Linux)

## Description

Create EC2 server instances for both Linux and Windows and verify that the instances are available. The screenshots document the resulting Linux and Windows server environments.

## Learning outcomes

- Recognize the main steps in provisioning an EC2 instance.
- Distinguish between Linux and Windows instance access.
- Inspect the provisioned instances and retain setup evidence.
