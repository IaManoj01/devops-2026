# Users, Groups, chmod, and chgrp Practice

## Description

Practice Linux account and group commands together with permission and group-ownership changes. The task demonstrates how user/group administration and filesystem permissions work together to control access.

## Learning outcomes

- Work with user and group administration commands.
- Change file permissions with `chmod`.
- Change group ownership with `chgrp`.
- Verify the resulting ownership and permissions.
