# Day 2 - Linux administration and AWS foundations

The exercises combine command-line practice and user/group administration with AWS virtual machines, SSH key-format conversion, and static website deployment.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 Linux Commands/description.md>) - Practice a set of useful Linux commands and capture their output.
2. [Deploy static page in AWS](<Task 2 - Deploy static page in AWS/description.md>) - Host and verify a static webpage using AWS infrastructure.
3. [Create server in AWS (Windows & Linux)](<Task 3 - Create server in AWS (windows & linux)/description.md>) - Provision and access EC2 instances running Linux and Windows.
4. [Convert .ppk to .pem](<Task 4 - Convert (.ppk to .pem)/description.md>) - Convert an SSH private key between PuTTY PPK and PEM formats.
5. [Practice users, groups, chmod, and chgrp](<Task 5 - Practice (user,group, chmod, chgrp)/description.md>) - Practice account, group, ownership, and permission commands.
