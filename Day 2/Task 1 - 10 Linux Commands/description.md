# 10 Linux Commands

## Description

Practice ten useful Linux commands and capture their output. The task reinforces shell navigation and routine inspection of files and system state; consult the screenshot for the commands exercised.

## Learning outcomes

- Execute common Linux commands in a terminal.
- Interpret command output in context.
- Retain a concise record of practical command-line work.
