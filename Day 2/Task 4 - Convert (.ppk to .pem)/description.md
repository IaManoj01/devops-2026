# Convert a PPK Key to PEM

## Description

Convert an SSH private key from PuTTY's PPK format to PEM format for use with compatible SSH tools and workflows. Handle private key files carefully and keep them out of public repositories.

## Learning outcomes

- Recognize the PPK and PEM private-key formats.
- Convert a key to the format required by a client or platform.
- Understand that private keys must be stored and shared securely.
