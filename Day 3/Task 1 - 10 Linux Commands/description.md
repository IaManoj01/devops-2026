# 10 Linux Commands

## Description

Continue hands-on Linux command practice by running a set of commands and recording their output. The screenshots provide examples of the commands and terminal results captured for this session.

## Learning outcomes

- Improve fluency with the Linux shell.

- Maintain evidence of repeated command-line practice.
