# Day 3 - AWS identity, storage, and DNS

This day builds on Linux command practice and introduces access management with IAM, public and private S3 objects, and DNS configuration using Amazon Route 53.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 Linux Commands/description.md>) - Reinforce Linux command usage with captured examples.
2. [Create IAM groups and configure permissions](<Task 2 - Create IAM groups and configure permissions/description.md>) - Organize identities with groups, users, roles, MFA, and access policies.
3. [Public and private objects](<Task 3 - Public and private objects/description.md>) - Compare S3 object access settings and verify intended access.
4. [DNS and Amazon Route 53](<Task 4 - Domain Name System (DNS) and Amazon Route 53/description.md>) - Explore DNS concepts and configure a Route 53-backed name for a website.
