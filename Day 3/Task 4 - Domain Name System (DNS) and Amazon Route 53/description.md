# DNS and Amazon Route 53

## Description

Explore how DNS names resolve to a website and configure a name using Amazon Route 53. The captured evidence includes Route 53 settings, a namespace configuration, and the resulting webpage.

## Learning outcomes

- Explain the role of DNS in resolving a human-readable name.
- Understand how Route 53 participates in DNS hosting and routing.
- Verify the web experience associated with the configured name.
