# Public and Private S3 Objects

## Description

Create an S3 bucket and compare public and private object access. The screenshots show the bucket and objects as well as examples of the two access patterns. Keep public access limited to objects intended for public distribution.

## Learning outcomes

- Understand the distinction between a bucket and the objects stored in it.
- Compare public and private object access.
- Recognize the security implications of exposing an object publicly.
