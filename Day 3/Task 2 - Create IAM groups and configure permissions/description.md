# Create IAM Groups and Configure Permissions

## Description

Organize AWS identities with IAM users and groups, configure roles and MFA, and examine how policies grant or restrict access to S3. The evidence includes both access-with-policy and access-without-policy examples to help compare the outcomes of policy-based permissions.

## Learning outcomes

- Understand the relationship between IAM users, groups, roles, and policies.
- Configure identity safeguards such as MFA.
- Compare S3 access behavior with and without an appropriate policy.
- Apply least-privilege thinking when granting permissions.
