# Linux Server Monitoring with Prometheus and Grafana

## Description

Configure Prometheus and a host-metrics exporter to collect Linux server metrics, then use Grafana to visualize the data. The screenshots show the Prometheus targets before and after exporter configuration, as well as the resulting metrics and dashboards.

## Learning outcomes

- Understand the roles of Prometheus, an exporter, and Grafana.
- Confirm target discovery and scrape status.
- Inspect collected host metrics.
- Use dashboards to visualize infrastructure measurements.
