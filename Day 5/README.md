# Day 5 - AWS audit and infrastructure monitoring

This day covers Linux command practice, AWS account-activity auditing with CloudTrail, event notifications and queueing for EC2 monitoring, and Linux host visualization with Prometheus and Grafana.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 Linux commands/description.md>) - Practice Linux commands and retain screenshots of the results.
2. [AWS CloudTrail account activity](<Task 2 - Create an AWS CloudTrail to record account activity/description.md>) - Configure CloudTrail logging and its S3 destination.
3. [EC2 monitoring with CloudWatch, SNS, and SQS](<Task 3 - AWS EC2 Monitoring with CloudWatch, SNS, and SQS/description.md>) - Configure an alarm and notification/queue path and verify the resulting message.
4. [Linux monitoring with Prometheus and Grafana](<Task 4 - Linux Server Monitoring and Visualization Using Prometheus and Grafana/description.md>) - Collect host metrics and view them in Prometheus and Grafana.
