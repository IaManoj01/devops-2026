# Create AWS CloudTrail to Record Account Activity

## Description

Configure an AWS CloudTrail trail to record account activity and deliver log files to an S3 bucket. The screenshots document trail creation and the associated logging bucket and log objects.

## Learning outcomes

- Understand CloudTrail's role in recording AWS account activity.
- Configure a trail and a destination for its logs.
- Locate the resulting log artifacts in S3.
- Treat audit logs as important operational and security evidence.
