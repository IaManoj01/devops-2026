# AWS EC2 Monitoring with CloudWatch, SNS, and SQS

## Description

Set up an EC2 monitoring and notification flow using CloudWatch alarms, Amazon SNS, and Amazon SQS. The captured work covers an EC2 instance, alarm configuration and state, notification setup, email confirmation, and successful SQS message polling.

## Learning outcomes

- Configure an alarm to observe an EC2 metric.
- Use SNS to distribute an alarm notification.
- Route notifications to an SQS queue and poll a message.
- Verify the monitoring path through observable alarm and message results.
