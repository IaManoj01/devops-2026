# Day 4 - Docker containers and images

The tasks combine Linux command practice with running a WordPress and MySQL container pair and building, modifying, and testing a custom Docker image from a Dockerfile.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 linux commands/description.md>) - Continue practicing Linux commands and interpreting their output.
2. [WordPress and MySQL containers on AWS EC2](<Task 2 - Create WordPress and MySQL Docker Containers on AWS EC2/description.md>) - Run the application and database containers and troubleshoot their setup.
3. [Create and modify a custom Docker image](<Task 3 - Create and Modify a Custom Docker Image Using a Dockerfile/description.md>) - Build and test Docker image revisions from a Dockerfile.
