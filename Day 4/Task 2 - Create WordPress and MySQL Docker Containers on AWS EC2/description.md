# WordPress and MySQL Docker Containers on AWS EC2

## Description

Run WordPress and MySQL containers on an AWS EC2 host. The saved evidence records Docker installation, image pulls, and troubleshooting of a MySQL container issue. A working application requires the database and web application containers to be configured to communicate and use compatible settings.

## Learning outcomes

- Prepare an EC2 host for Docker workloads.
- Pull and run application and database container images.
- Diagnose container startup or configuration problems.
- Understand the dependency between WordPress and its MySQL service.
