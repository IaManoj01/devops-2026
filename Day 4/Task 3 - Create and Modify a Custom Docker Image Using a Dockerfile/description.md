# Create and Modify a Custom Docker Image Using a Dockerfile

## Description

Create a Dockerfile, build a custom image, and modify the image for a second iteration. Test the resulting containers to check that each version behaves as expected.

## Learning outcomes

- Describe how a Dockerfile defines image build steps.
- Build and run a custom image.
- Make a change, rebuild the image, and verify the updated result.
- Inspect running containers during testing.
