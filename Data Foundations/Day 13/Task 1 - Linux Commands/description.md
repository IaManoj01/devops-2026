# Linux Commands

## Description

Practice common Linux commands and capture terminal output as evidence. The exercise reinforces command syntax and familiarity with everyday shell operations.

## Learning outcomes

- Execute common Linux commands.
- Observe and interpret command output.
- Strengthen Linux command-line fluency.
