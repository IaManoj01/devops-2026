# SQL Database Setup and Query Analysis Using Dataset 2

## Description

Create and query the `space_communications` database, which contains related `spacecraft` and `communication_logs` tables. The exercise loads spacecraft and communication records, verifies the data, and uses four queries to explore the communications dataset.

## Learning outcomes

- Create databases and related tables using primary and foreign keys.
- Insert records and verify table contents and row counts.
- Filter results with `LIKE` and `BETWEEN`, then sort and limit output.
- Use `LEFT JOIN`, grouping, and aggregate functions to analyze communication logs and compare signal strength across agencies.
