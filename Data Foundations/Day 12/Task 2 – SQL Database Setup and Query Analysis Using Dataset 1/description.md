# SQL Database Setup and Query Analysis Using Dataset 1

## Description

Use MySQL to verify and analyze a space-mission dataset stored in the `data_foundation` database. The work explores the `space_missions` and `mission_observations` tables, checks their contents, and uses four queries to analyze missions and observations.

## Learning outcomes

- Inspect databases, tables, and records using `USE`, `SHOW TABLES`, `DESCRIBE`, `SELECT`, and `COUNT()`.
- Filter and sort missions by status and launch date.
- Group observation records and calculate counts, averages, and totals.
- Join mission and observation data, and use a subquery to compare data collection with its average.
