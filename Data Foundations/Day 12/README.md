# Day 12 - Data Foundations

This day combines Linux command practice with SQL database setup and analysis. The SQL exercises use space-mission and spacecraft-communication datasets to practice querying, filtering, aggregation, and joins.

## Tasks

1. [Linux Commands](<Task 1 - Linux Commands/description.md>) - Practice common Linux commands and capture terminal output.
2. [SQL Database Setup and Query Analysis Using Dataset 1](<Task 2 – SQL Database Setup and Query Analysis Using Dataset 1/description.md>) - Set up and query related space-mission and observation tables.
3. [SQL Database Setup and Query Analysis Using Dataset 2](<Task 3 – SQL Database Setup and Query Analysis Using Dataset 2/description.md>) - Create and query spacecraft and communication-log tables.
