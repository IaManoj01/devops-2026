# Data Analysis on 5 Different Products

## Description

Explore data-analysis scenarios across five product contexts using the provided space-mission analytics materials. The exercise focuses on applying analytical thinking to different questions and interpreting data in context.

## Learning outcomes

- Relate analysis questions to different product scenarios.
- Use a dataset and written scenarios to guide an analysis.
- Practice interpreting data to support product-focused insights.
