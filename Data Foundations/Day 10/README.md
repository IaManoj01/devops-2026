# Day 10 - Data Foundations

This day introduces data analysis foundations alongside Linux command practice. The exercises explore where NumPy and pandas are used, compare analysis with and without NumPy, and apply Python data libraries to a space-mission dataset.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 Linux Commands/description.md>) - Practice common Linux commands and capture terminal output.
2. [Data Analysis on 5 Different Products](<Task 2 - Data Analysis on 5 diff prod/description.md>) - Work through space-mission analytics scenarios to explore data analysis across product contexts.
3. [Use Cases of NumPy and pandas in Companies](<Task 3 - Use Cases of Libraries[Numpy ,pandas ]in companies/description.md>) - Review business use cases for the NumPy and pandas Python libraries.
4. [Analysis With and Without NumPy](<Task 4 - Analysis w Numpy & wo Numpy/description.md>) - Compare data analysis approaches using NumPy and standard Python.
5. [Complete Data Analysis Using NumPy](<Task 5 - Complete Data Analysis using Numpy/description.md>) - Apply NumPy and pandas commands to analyze a space dataset.
