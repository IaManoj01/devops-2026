# Complete Data Analysis Using NumPy

## Description

Complete a data-analysis exercise using NumPy and pandas with the provided space dataset. The materials include a command reference and screenshots documenting the analysis workspace and dataset.

## Learning outcomes

- Apply NumPy and pandas commands in a data-analysis workflow.
- Work with a dataset to explore and interpret its contents.
- Practice using a notebook-based environment for analysis.
