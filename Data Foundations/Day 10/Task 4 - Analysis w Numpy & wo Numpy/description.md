# Analysis With and Without NumPy

## Description

Compare approaches to data analysis with NumPy and without it. The exercise highlights how a numerical-computing library can affect the way data operations are expressed and performed.

## Learning outcomes

- Compare analysis workflows with and without NumPy.
- Understand the role of a numerical-computing library in Python analysis.
- Evaluate differences in approach when working with data.
