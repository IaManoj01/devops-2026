# Day 10 - Data Foundations

This day builds foundational data-analysis skills through practical exercises with Python data libraries. It combines Linux command revision with exploration of NumPy and pandas use cases, analysis approaches with and without NumPy, and a fuller analysis of a space dataset.

The task folders contain the associated written scenarios, analysis material, dataset, and screenshots. Each task has its own `description.md` so its purpose and evidence can be understood independently, while the day README remains a concise index.
