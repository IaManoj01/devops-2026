# Pandas Data Cleaning, Transformation, and Visualization

## Description

Work with a space-missions dataset in pandas to identify and address data-quality issues, transform columns, inspect outliers, and visualize the results. The walkthrough also exports the cleaned dataset to CSV.

## Learning outcomes

- Inspect missing, duplicate, inconsistent, and invalid data.
- Clean and transform values and data types with pandas.
- Use summary statistics and visualizations to examine distributions and outliers.
- Export a cleaned dataset for later use.
