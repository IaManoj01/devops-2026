# 10 Linux Commands

## Description

Practice ten Linux commands and capture terminal output as evidence. The exercise reinforces command syntax and familiarity with common shell operations.

## Learning outcomes

- Execute common Linux commands.
- Observe and interpret command output.
- Strengthen everyday Linux command-line fluency.
