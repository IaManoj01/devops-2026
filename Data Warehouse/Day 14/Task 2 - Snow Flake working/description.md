# Snowflake Employee Data Loading

## Description

Use Snowflake to create and manage the `COMPANY_DATA` database, the `HR_RECORDS` schema, and the `STAFF_WH` virtual warehouse. Create the `EMPLOYEE_DETAILS` table and a CSV file format, upload an employee CSV file to an internal stage, load it with `COPY INTO`, and verify the resulting records.

## Learning outcomes

- Inspect the active Snowflake session and manage databases, schemas, and virtual warehouses.
- Create a table for employee details and inspect its structure.
- Configure a CSV file format and an internal stage for data loading.
- Load staged CSV data with `COPY INTO` and verify the loaded records.
