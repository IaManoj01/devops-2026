# Day 14 - Data Warehouse

This day combines Linux command practice with a Snowflake data-loading exercise. The Snowflake practical creates a company database and HR schema, prepares an employee table and CSV file format, stages an employee file, and loads and verifies the records.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 linux commands/description.md>) - Practice common Linux commands and capture terminal output.
2. [Snowflake Employee Data Loading](<Task 2 - Snow Flake working/description.md>) - Set up Snowflake database objects and load employee records from a staged CSV file.
