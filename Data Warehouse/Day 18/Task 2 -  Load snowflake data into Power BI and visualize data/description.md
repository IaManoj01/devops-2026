# Load Snowflake Data into Power BI and Visualize Data

## Description

Use Snowflake as the source data warehouse and Power BI as the reporting layer to load, transform, and visualize sales data. The exercise demonstrates how to move warehouse data into a BI model and create dashboard-ready insights.

## Learning outcomes

- Connect and prepare Snowflake data for downstream reporting.
- Model cleaned sales data in Power BI.
- Visualize business trends and summary metrics from warehouse data.
