# Power BI Performance Analyzer

## Description

Use Power BI's Performance Analyzer to record report visual activity, inspect rendering and query timings, and identify the slowest visuals. The captured analysis reports that all visuals rendered in under one second.

## Learning outcomes

- Record visual activity using the Performance Analyzer.
- Compare visual load timings and their contributing processes.
- Identify potential report performance bottlenecks.
