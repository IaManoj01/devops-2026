# DAX Functions

## Description

Create and document ten DAX measures for the Retail Mart Performance Dashboard using the `MANOJ_INDIAN_SALES` table. The measures calculate core business KPIs for dashboard visuals and scorecards.

## Learning outcomes

- Use DAX aggregation and distinct-count functions to calculate business metrics.
- Define measures for analyzing retail sales performance.
- Apply measures as inputs to Power BI visualizations.
