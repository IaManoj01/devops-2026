# New Columns and New Measures

## Description

Load the Indian retail mart dataset into Snowflake, connect the data to Power BI, and extend the model with calculated columns, measures, and slicers. The documentation covers Snowflake object and staging setup, data loading, and Power BI model enhancements.

## Learning outcomes

- Create Snowflake warehouse, database, schema, table, file format, and stage objects.
- Load and verify the retail sales dataset, then connect it to Power BI.
- Add calculated columns and measures to support sales analysis.
- Configure slicers for interactive report exploration.
