# Day 15 - Data Warehouse

This day combines Linux command practice with a Snowflake student-data exercise and an AWS VPC implementation. The Snowflake practical loads student academic performance records into a staged data warehouse table, while the AWS task documents public and private network components and EC2 access.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 linux commands/description.md>) - Practice common Linux commands and capture terminal output.
2. [Snowflake Student Data Loading](<Task 2 - Snow Flake working/description.md>) - Set up Snowflake database objects and load and verify student records.
3. [Design and Implement a Basic AWS VPC](<Task 3 - Design and implement a basic AWS Virtual Private Cloud (VPC)/description.md>) - Configure a VPC with public and private network components and document the EC2 and application evidence.
