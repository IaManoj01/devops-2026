# Snowflake Student Data Loading

## Description

Use Snowflake to create and manage the `STUDENT_DATA` database, the `ACADEMICS` schema, and the `STUDENT_WH` virtual warehouse. Create the `STUDENT_DETAILS` table and a CSV file format, upload student academic performance data to an internal stage, load it with `COPY INTO`, and verify the records.

## Learning outcomes

- Inspect the active Snowflake session and manage databases, schemas, and virtual warehouses.
- Create a student table and inspect its structure.
- Configure a CSV file format and an internal stage for data loading.
- Load staged CSV data with `COPY INTO` and verify the student records.
