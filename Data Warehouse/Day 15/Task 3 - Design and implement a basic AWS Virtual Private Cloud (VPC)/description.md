# Design and Implement a Basic AWS VPC

## Description

Document a basic AWS VPC setup with public and private subnets, route tables, internet and NAT gateways, and separate security groups. The screenshots also show EC2 server access and application home and login pages.

## Learning outcomes

- Identify the main components of a VPC with public and private subnets.
- Configure gateways, route tables, and security groups for the network.
- Review EC2 server access and the deployed application's pages.
