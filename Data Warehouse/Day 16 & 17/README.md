# Days 16 & 17 - Data Warehouse

These days combine Linux command practice with a sales analytics workflow spanning Snowflake and Power BI. The Snowflake practical ingests customer, product, and sales CSV datasets, cleans and analyzes the data, and compares query performance. The Power BI practical cleans and models the same datasets and builds sales visualizations.

## Tasks

1. [10 Linux Commands](<Task 1 - 10 linux commands/description.md>) - Practice common Linux commands and capture terminal output.
2. [Snowflake Multi-Dataset Ingestion, Transformation, and Query Optimization](<Task 2 - Snowflake – Multi-Dataset Ingestion, Transformation & Query Performance Optimization/description.md>) - Load customer, product, and sales data into Snowflake, create cleaned datasets, run analytical SQL, and compare query performance.
3. [Power BI Data Transformation and Modeling](<Task 3 - POWER BI – DATA TRANSFORMATION, DATA MODELING/description.md>) - Clean the sales datasets, model their relationships, and create sales visualizations in Power BI Desktop.
