# Power BI Data Transformation and Modeling

## Description

Use Power BI Desktop to load and prepare customer, product, and sales datasets for analysis. Clean the tables by changing data types, trimming and standardizing text, replacing empty or null values, and removing duplicates. Model the one-to-many relationships from Customers and Products to Sales, then create visualizations for payment status, quantity by product, sales by city, and sales transactions over time.

## Learning outcomes

- Load CSV datasets into Power BI Desktop.
- Clean customer, product, and sales data using Power Query transformations.
- Build and inspect relationships between dimension tables and sales transactions.
- Create visualizations to explore payment status, product quantities, sales by city, and sales over time.
