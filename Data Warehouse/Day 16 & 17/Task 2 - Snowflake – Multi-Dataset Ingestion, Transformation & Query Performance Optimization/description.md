# Snowflake Multi-Dataset Ingestion, Transformation, and Query Optimization

## Description

Use Snowflake to build a sales analytics workflow with customer, product, and sales CSV datasets. Set up a database with raw and cleaned schemas and a virtual warehouse, ingest the source files into raw tables, and prepare cleaned tables by handling missing values, converting data types, and removing duplicate records. Explore the data with analytical SQL, then compare an original and an optimized query using execution times and Snowflake Query Profile.

## Learning outcomes

- Organize Snowflake databases, schemas, warehouses, tables, file formats, and an internal stage.
- Load and verify related CSV datasets in Snowflake.
- Inspect data quality, handle missing values, convert data types, and remove duplicates.
- Analyze sales with filters, joins, and aggregations.
- Compare SQL query performance and review query profiles.
